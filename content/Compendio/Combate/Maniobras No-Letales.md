Ataques indirectos que intentan derrotar a un enemigo sin herirle.

- La maniobra se resuelve haciendo una tirada de Ataque opuesta a la reacción (usualmente Defensa) del objetivo.
- Cada maniobra requiere una Ventaja de Ataque determinada para tener éxito.
- No se aplica el -3 al Ataque
- La Ventaja de Ataque no causa Heridas ni Moratones directos, sino un resultado específico. 
- Las Pifias pueden resultar en Heridas para el Defensor o incluso el Atacante.

| Maniobra               | Total de Ataque           | Opciones de Defensa                                     | Ventaja Requerida |
| ---------------------- | ------------------------- | ------------------------------------------------------- | ----------------- |
| **Barrido o Tropiezo** | Ataque de Pelea           | Defensa o Esquivar + Destreza + Tamaño + Dado de Estrés | 3+                |
| **Clavada**            | Ataque de Pelea           | Defensa o Esquivar + Fuerza + Tamaño + Dado de Estrés   | 6+                |
| **Derribo o Placaje**  | Ataque de Pelea           | Defensa o Esquivar + Destreza + Tamaño + Dado de Estrés | 1+                |
| **Desarme**            | Cualquier ataque          | Total de Defensa o Esquivar                             | 9+                |
| **Desmonte**           | Ataque de Pelea o de Arma | Defensa o Esquivar + Destreza + Montar + Dado de Estrés | 6+                |
| **Forcejeo**           | Ataque de Pelea           | Defensa o Esquivar + Fuerza + Tamaño + Dado de Estrés   | 1+                |
| **Pugna por Objeto**   | Ataque de Pelea           | Defensa o Esquivar + Fuerza + Tamaño + Dado de Estrés   | 6+                |
| **Pugna por Arma**     | Ataque de Pelea           | Defensa o Esquivar o Ataque Cuerpo a Cuerpo             | 12+               |
