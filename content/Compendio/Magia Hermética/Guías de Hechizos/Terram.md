Este arte se refiere a lo que ahora llamaríamos materia inerte -aunque tal concepto es moderno. Además de tratar con la tierra, la piedra, la arcilla, el metal y el vidrio, los hechizos de Terram también podrán afectar a los objetos inanimados en general. 

> [!example] 
>  [[Honda Mágica (ReTe10)]] puede arrojar diversos tipos de objetos inertes.

Aunque los hechizos de Terram afectan a todo tipo de objetos sólidos, ciertos materiales resultan más complicados que otros. Aquí se muestran, en orden creciente de dificultad, los materiales que se ven afectados por los hechizos de Terram: 
1. tierra (arena, barro, lodo), 
2. arcilla, cerámica
3. piedra, 
4. vidrio, 
5. metal
6. gemas.

Cada uno de estos niveles de dificultad no tiene por qué representar el incremento de un nivel de magnitud.
 
#### Objetivo base
Dependerá del material afectado:
- Para arena, barro, lodo, arcilla o sustancias similares, sería un volumen de 5 metros cúbicos de material; 
- para piedra, sería un volumen de 0,5 metros cúbicos; 
- para metales, unos 0,03 metros cúbicos; mientras que para metales nobles sería una décima parte de esto último. 
- Para piedras preciosas, el objetivo base Individuo es de unos 15 centímetros cúbicos.

## Creo [[Terram]]

### Consideraciones

#### Generación de materia inerte
Crear tierra en formas elaboradas o con alguna propiedad antinatural es un nivel de magnitud mayor que el que aparece listado en las guías. 

#### Improntas
Las que son comunes de ver en los hechizos de CrTe implican aspectos extraños en los objetos creados, como barro de un determinado color o textura. 

#### Pifias
Las pifias de CrTe pueden enterrar al lanzador en tierra o piedra, o pueden crear materiales erróneos o hacerlos aparecer en el lugar equivocado.

### Guías de Creo Terram 

| N  | Efectos                            |
|----|------------------------------------|
| 1  | Crea arena, barro, lodo o arcilla. |
| 2  | Crea piedra o cristal.             |
| 3  | Crea un metal.                     |
| 15 | Crea un metal noble.               |
| 25 | Crea una piedra preciosa.          |

## Intellego Terram 

### Consideraciones 

#### Inspección de materia inerte
El nivel de los hechizos de InTe no se ve afectado por el material del objeto. 

#### Pifias
Las pifias de Intellego Terram normalmente dan información falsa.

|----|----------------------------------------------------------------------------------------------------------------------------------------------|

|    | Vé un objeto y sus alrededores.                                                                                                              |

## Muto Terram 

### Consideraciones 

#### Transformación de material inerte
Los objetivos de la guía son para transformar el barro. 
- Transformar la arena, el polvo, la arcilla o un material distinto en arena, polvo o arcilla, tiene el mismo nivel de magnitud que el barro. 
- Transformar la piedra o el vidrio, o un material distinto en piedra o vidrio suma una magnitud. 
- Transformar metales o gemas, o un material distinto en un metal o una gema, suma dos magnitudes. 

Estos ajustes solo se aplican una vez, por lo que transformar un metal en otro distinto suma solo dos magnitudes. 

La cantidad de material que se puede transformar está limitado por las guías destinadas a tal fin. Así puedes transformar un metro cúbico de piedra en una gema de quince cls cúbicos de volumen, con base Individuo. 

#### Pifias
Las pifias más graves de MuTe suelen convertir al lanzador en piedra o metal, aunque aquellas más leves transforman el objeto equivocado o transforman el objetivo de una forma no deseada.

### Guías de Muto Terram 

| N  | Efectos                                                                                    |
|----|--------------------------------------------------------------------------------------------|
| 1  | Cambia una propiedad del barro.                                                            |
| 2  | Transforma el barro en otro tipo de tierra natural (por ejemplo, la arena en arcilla).     |
| 3  | Transforma el barro de forma que sea ligeramente artificial (puede necesitar requisitos).  |
|    | Transforma el barro en un líquido o gas (con requisitos).                                  |
|    | Transforma el barro en piedra o viceversa.                                                 |
| 4  | Transforma el barro de forma que sea muy artificial (suele necesitar requisitos).          |
|    | Trasforma el barro en una mezcla de líquidos, sólidos y gases (con requisitos).            |
|    | Trasforma el barro en una planta (con requisitos)                                          |
|    | Hace que algo incremente ocho veces su volumen inicial.                                    |
| 5  | Transforma el barro en un liquido o gas ligeramente artificiales (con requisitos).         |
|    | Transforma el barro en un animal (con requisitos).                                         |
| 10 | Transforma el barro en un líquido o gas muy artificial (con requisitos).                   |

## Perdo Terram 

### Consideraciones 
#### Destrucción de materia inerte
- Utiliza el mismo nivel para destruir tierra cuando destruyas arena, fango o arcilla. 
- Para destruir piedra o video, suma una magnitud. 
- Para destruir metales o gemas, suma dos magnitudes. 

#### Pifias
Las pifias de Perdo Terram, ademas de destruir el objetivo equivocado, pueden destruir el suelo sobre el que esta el lanzador o los metales que lleve encima.

### Guías de Perdo [[Terram]]
| N   | Efectos             |
| --- | ------------------- |
| 2   | Reblandece el barro |
| 3   | Destruye el barro   |

## Rego Terram 

### Consideraciones 

#### Controlar materia inerte
- las guías a continuación valen para controlar barro, arena, lodo o arcilla. 
- Para controlar piedra o vidrio suma una magnitud, 
- Para controlar metal o gemas, suma dos magnitudes. 
Manipular objetos con gran precisión puede aumentar el nivel, dependiendo del grado de precisión requerido. 

#### Pifias
Las pifias de ReTe suelen hacer que el lanzador se vea golpeado por una gran cantidad de piedras voladoras.

### Guias de Rego Terram 

| N   | Efectos                                                                                                                                                                                       |
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Gen | Protege contra criaturas de piedra de un reino específico (Divino, Feérico, Infernal o Mágico), con Poder menor que el nivel del hechizo (Alcance Toque, Duración Anillo, Objetivo Círculo).  |
| 1   | Controla o mueve de forma natural el barro.                                                                                                                                                   |
| 2   | Controla o mueve de forma ligeramente antinatural el barro.                                                                                                                                   |
|     | Mantiene el barro alejado de ti, bajo tu control directo (es decir, debes ser consciente de su presencia).                                                                                    |
| 3   | Controla o mueve de forma muy antinatural el barro                                                                                                                                            |
| 5   | Mantiene todo el barro alejado de tu cuerpo o protege a un objetivo del barro.                                                                                                                |
